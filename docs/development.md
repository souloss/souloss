# Panel development

The profile README is kept focused on the rendered cards. This document covers configuration and development.

## Configuration

Edit `config/profile.toml` to change the GitHub account, timezone, theme colors, number of repositories, or repository filters. Recent repositories and language byte counts are fetched from GitHub's public REST API. The scheduled workflow supplies its job token to increase the API rate limit; no personal access token is required for public data.

The contribution snake is generated by [Platane/snk](https://github.com/Platane/snk), then wrapped in the shared SVG panel frame.

## Render locally

Use Python 3.11 or newer. The recent repositories card can be rendered with:

```sh
python scripts/generate.py dist
```

## Add a card

Keep data fetching in a provider, convert the response into a small plain-data structure, and add a renderer in `scripts/cards.py` that returns a complete SVG. Shared colors, XML escaping, and the outer SVG document are in `scripts/theme.py`. Update the workflow and README image references when adding an output card.

The workflow refreshes the panel daily and restores the previous output first, so a failed data request does not replace the existing card with a broken image. The language card aggregates GitHub's per-repository language byte counts, using the same fork and archive filters as the recent repositories card.
